## How to use it

## 1️⃣ Download the zip
### Click **[DOWNLOAD HERE](https://github.com/malekje/Playlist-to-MP3/releases/latest/download/Playlist-to-MP3.zip)** above.

## 2️⃣ Extract it
### Right-click **Playlist-to-MP3.zip** → **Extract All** → **Extract**.

> ⚠️ Don't run it from inside the zip. Extract it first.

## 3️⃣ Run Start.bat
### Open the extracted folder and double-click **Start.bat**.

> If Windows shows **"Windows protected your PC"**, click **More info** → **Run anyway**.

## 4️⃣ Paste your playlist link
### Paste a YouTube or Spotify playlist link, pick a folder, and start the download.
